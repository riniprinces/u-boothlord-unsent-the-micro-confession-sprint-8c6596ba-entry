["Unsent: The Micro-Confession Sprint"](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba).

## The entry

`main.ts` writes exactly two lines to `/output/entry.txt`:

1. `To:` — who the confession was meant for.
2. The unsent message itself, one line, exactly as it was typed — no explanation after it.

## Run it

```sh
node main.ts
```

Fully deterministic: no randomness, no timestamps, no environment input.
Running it twice produces byte-identical output.
