A two-line unsent micro-confession: a To: line and the one line never sent. A thank-you that could never be sent, because the sender never learned the name of the person it was for — the ward number is the only address the message ever had.

## Run it

```sh
node main.ts
```

This writes the confession to `/output/entry.txt` (94 characters: a `To:` line and one message line, nothing after it).
